## Objetivo
Emitir un `nonce` y validar la firma del dispositivo (`device_bindings.public_key`) para abrir
sesion y emitir JWT/refresh.

## Contexto embebido
- Liveness del servidor **no** se usa en login (D07).
- La biometria es local; el servidor valida el `nonce` firmado con la clave publica del dispositivo.
- JWT corto + refresh rotativo; revocacion por lista negra en Redis.

## Context pack
- L0. L1: `docs/modules/README.md#identity`.
- L2: `docs/03b-diccionario-de-datos.md#43-device_bindings`,
  `docs/06-epica-1-identidad-kyc.md#hu03---autenticacion-biofacial-y-multi-factor-must-5-sp-sprint-1`.

## Frontera
- Puede tocar: `identity/domain/`, `service/`, `api/`.
- Prohibido: usar el microservicio KYC aqui.

## Modelo de datos
`device_bindings`, `sessions`, `credentials`.

## API
- `POST /auth/login/challenge` -> `nonce`.
- `POST /auth/login/facial` -> verifica firma y devuelve tokens.

## Reglas
- `nonce` de un solo uso y TTL corto.
- Registrar dispositivo si es confiable.

## CA
- `CA-01` de HU03.

## Pruebas
- Firma valida; nonce reutilizado; firma invalida.
