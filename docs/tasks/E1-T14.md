## Objetivo
Implementar el login alterno con PIN (hash) con contador de intentos fallidos y bloqueo temporal
tras 5 fallos, notificando al cliente.

## Contexto embebido
- Tras 5 intentos fallidos: bloqueo temporal + notificacion.
- El bloqueo se registra sin exponer datos sensibles.
- `auth.max_failed_attempts` configurable.
