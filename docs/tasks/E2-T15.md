## Objetivo

Construir la agenda de beneficiarios frecuentes en Flutter: listado con busqueda en tiempo real por
alias/nombre, agrupacion (p. ej. por banco o alfabetica), alta/edicion/eliminacion con confirmacion
de seguridad y muestra de datos enmascarados.

## Alcance

- **Incluye:** feature `lib/features/beneficiaries/` (`data/`, `models/`, `presentation/`,
  `beneficiaries_routes.dart`), busqueda con debounce contra `GET /beneficiaries?q=`, agrupacion,
  formularios de alta/edicion, soft-delete con dialogo de confirmacion.
- **No incluye:** el tope pre-aprobado en el flujo de pago (`E2-T14`), el reto biometrico
  (`E2-T21`), el backend (`E2-T13`).

## Modelo de datos

Sin persistencia local de dinero. Modelo Dart de beneficiario (id, alias, bank_code,
account_or_cci_masked, holder_name_masked, preapproved_limit_minor, currency, status). No guardar
CCI completo sin cifrar en disco.

## API / eventos

- **Endpoints consumidos:** `GET /beneficiaries?q=`, `POST /beneficiaries`,
  `PUT /beneficiaries/{id}`, `DELETE /beneficiaries/{id}`.
- **Eventos:** ninguno (cliente).
- **Errores a mapear:** `NOT_FOUND`, `NOT_AUTHORIZED`, `VALIDATION_ERROR`,
  `DUPLICATE_BENEFICIARY`.

## Reglas de negocio

- Busqueda en tiempo real con debounce; resultado `< 1 s` percibido; soporta hasta 100 registros.
- Agrupacion: alfabetica por alias o por `bank_code` (criterio de UI, no de negocio).
- Alta/edicion de tope pre-aprobado solo por el titular (el backend valida; la UI no lo decide).
- Eliminar exige confirmacion de seguridad (dialogo explicito) y muestra `DELETED` de forma
  optimista solo tras respuesta 2xx.

## Criterios de aceptacion (CA)

- `CA-02` de HU07: busqueda en tiempo real por alias/nombre.
- `CA-04` de HU07: editar/eliminar con confirmacion.
- `CA-03` de HU07: la UI permite fijar/editar el tope (persistido por `E2-T13`).

## Pruebas requeridas

- Camino feliz: listar, buscar, agrupar, alta, editar tope, eliminar con confirmacion.
- Errores: fallo de red, lista vacia, `403`/`404`, duplicado; estados de carga/error/vacio.
- Seguridad: datos enmascarados en la lista; el CCI no aparece completo en pantalla ni en logs.
