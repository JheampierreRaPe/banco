## Objetivo
Implementar el catalogo contable semilla y la creacion de subcuentas por cuenta de cliente
(disponible `2000-<cuenta>` y retenido `2100-<cuenta>`).

## Contexto embebido
- Catalogo minimo: `1000`, `2000`, `2100`, `2200`, `3000`, `4000`, `4100`, `4200`, `5000`, `6000`,
  `9100`.
- Cada cuenta de cliente tiene dos cuentas contables.
- `code` unico.
