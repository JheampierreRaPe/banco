## Objetivo
Implementar la verificacion de la cadena de hashes de `journal_entries` y `audit_log`, detectando
cualquier alteracion.

## Contexto embebido
- Cada registro guarda `prev_hash` y `hash`.
- La verificacion recorre la cadena y detecta rupturas.
- Base para la bitacora inalterable (HU23, post-MVP).

## Context pack
- L0. L1: `docs/modules/README.md#ledger` y `#audit`.
- L2: `docs/03b-diccionario-de-datos.md#142-audit_verifications`.

## Frontera
- Puede tocar: `ledger/service/` y `audit/`.
- Prohibido: modificar registros.

## Reglas
- Hash = SHA-256 del contenido + `prev_hash`.
- Alerta critica si la cadena no es valida.

## CA
- Soporte a `CA-02` de HU18.

## Pruebas
- Cadena valida; alteracion simulada detectada.
