## Objetivo

Validar con pruebas automatizadas la apertura de bolsillos, el redondeo automatico, el abono de
rendimientos, los traspasos por el motor y la UI (si existe), incluyendo idempotencia, saldo
insuficiente y cuadre contable. El QA no cambia codigo de producto salvo fixes minimos con
regresion.

## Alcance

- **Incluye:**
  - Suite `backend/tests/test_e7_t07_pockets_qa.py` (o equivalente):
    - apertura PEN/USD/EUR -> cuenta + bolsillo + subcuentas ledger; saldo 0; duplicados;
    - redondeo: 1,250/100 -> 50; multiplo -> 0; sin fondos -> skip; replay no duplica;
    - rendimiento: calculo, abono, asiento cuadrado, movimiento `YIELD`, idempotencia por periodo;
    - traspaso: cuenta->bolsillo, bolsillo->cuenta, bolsillo->bolsillo; cross-currency `422`;
      sin fondos `REJECTED`; replay no duplica; concurrencia sin sobregiro;
    - RBAC/aislamiento: solo el titular ve/mueve sus bolsillos; ajeno `404`;
    - frontera: `fx` no escribe `transactions`/`ledger`/`accounts`.
  - Pruebas de widget de `E7-T06` si existen (lista/traspaso/estados) o verificacion manual
    documentada.
  - Regresion: transferencias/QR/servicios/creditos verdes.
- **No incluye:** nuevas features, cambios de esquema, cambio de divisas (HU25), load/performance.

## Reglas de negocio

- El redondeo no bloquea el pago original; sin fondos -> skip.
- El rendimiento se abona una vez por periodo; asiento cuadrado.
- El traspaso no cruza monedas; no sobregira; replay no duplica.
- El bolsillo solo lo ve/mueve su titular.
- Sin PII en logs.
