## Objetivo

Definir el adaptador `FxRateProvider` que entrega **tipos de cambio** con `rate`, `source` y `ttl`,
con una implementacion `mock` determinista (tasas semilla) y una `http` con timeout/reintentos/
circuito y cache en proceso respetando el TTL. No persiste ni mueve dinero.

## Alcance

- **Incluye:**
  - Interfaz `FxRateProvider` con `get_rate(*, base, quote) -> FxRatePayload` y
    `get_rates(*, base) -> list[FxRatePayload]`.
  - `MockFxRateProvider` determinista con tasas semilla (`PEN/USD=3.80`, `PEN/EUR=4.10`,
    `USD/EUR=0.92`, inversas coherentes) y `ttl_seconds=60`; sin red.
  - `HttpFxRateProvider` con `GET {base_url}/rates?base=PEN` (contrato `docs/02#9`), timeout corto,
    reintentos con backoff y circuito; key solo en cabecera.
  - Cache en proceso por `(base, quote)` con TTL; `get_rate` devuelve cache si vigente y refresca al
    expirar; nunca cachea errores.
  - Fabrica `create_fx_rate_provider()` por `FX_RATE_PROVIDER` (`mock` por defecto; desconocido ->
    `mock`); errores `FX_RATE_UNAVAILABLE` (`503`) / `FX_RATE_TIMEOUT` (`502`).
  - Fallback a tasa semilla si el proveedor real falla (`D04`), documentado y auditable.
- **No incluye:** persistir `fx_rates` (`E7-T09`), cotizaciones (`E7-T09`), spread (`E7-T10`),
  ejecucion (`E7-T11`), UI (`E7-T12`), QA (`E7-T13`). No mueve dinero.

## Contexto embebido (decisiones que aplican)

- **Patron (`docs/02#9`):** `FxRateProvider` simula `GET /rates?base=PEN -> {quote, ttl}`; mock +
  http; cuando exista el proveedor real se agrega sin tocar el dominio.
- **Decision (`D04`):** proveedor real con **fallback a tasa semilla**; si no hay API, se usan tasas
  semilla.
- **Cache:** TTL por respuesta (`ttl_seconds`, default 60); no cachear errores; el TTL no debe
  superar la vigencia de la cotizacion (30 s en `E7-T09`).
- **Sin PII/secretos:** la key nunca va en URL/query/logs; solo cabecera.
- **Dinero:** `rate` es `Decimal`/string exacto, nunca `float`; la conversion a centimos la hace
  `E7-T09`/`E7-T11`.
- **Sin red en pruebas:** http con transporte inyectado/mockeado.

## Reglas de negocio

- `base != quote`; ambas ISO-4217; tasa `> 0`.
- El mock es determinista y coherente (inversa = `1/rate` redondeada a 8 decimales).
- Cache por par con TTL; expirado -> refresco; fallo -> fallback semilla (si esta configurado) o
  error tipado.
- No se cachean errores ni se sirve una tasa vencida como vigente.
- Sin PII/secretos en logs.

## Criterios de aceptacion (CA)

- `CA-01` (HU25 CA-01 base): el mock devuelve la tasa vigente con `source`/`ttl`; pares soportados.
- `CA-02`: la cache respeta el TTL y refresca al expirar; no cachea errores.
- `CA-03`: el http aplica timeout/reintentos/circuito y fallback semilla; errores tipados.
- `CA-04`: determinismo y coherencia de inversas; sin `float` en la tasa.
- `CA-05`: `ruff`/`black` limpios y `pytest` en verde.
