## Objetivo

Exponer la **cotizacion vigente** (`GET /fx/rates`) y **congelar una cotizacion por 30 s**
(`POST /fx/quotes`) con tasa, spread, montos origen/destino y `expires_at`; una cotizacion vencida
se reporta `EXPIRED` y no se puede ejecutar. El cliente ve el temporizador; el backend es la
autoridad de la vigencia.

## Alcance

- **Incluye:**
  - Servicio `get_rate(session, base, quote)` que consulta el adaptador `E7-T08`, persiste una fila
    `fx_rates` (snapshot con `source`/`ttl_seconds`) y devuelve la tasa vigente.
  - Servicio `create_quote(session, user_id, *, base, quote, source_amount_minor,
    spread=None)`:
    - valida monedas, monto `> 0` y `base != quote`;
    - obtiene tasa; aplica spread (`E7-T10`; default 0 en este brief);
    - calcula `target_amount_minor` con `Decimal` y redondeo entero documentado;
    - fija `expires_at = now + fx.quote_ttl_seconds` (default `30`, `config.parameters`);
    - persiste `fx_quotes` `ACTIVE`.
  - `get_quote(session, user_id, quote_id)`: si `now >= expires_at` y `status=ACTIVE`, la marca
    `EXPIRED` (on-read) y devuelve `EXPIRED`; ajeno -> `404` neutro.
  - Endpoints:
    - `GET /api/v1/fx/rates?base=PEN&quote=USD` -> `{base, quote, rate, source, fetched_at,
      ttl_seconds}`.
    - `POST /api/v1/fx/quotes` (`Idempotency-Key` opcional) body `{base, quote,
      source_amount_minor}` -> `201 {quote_id, base, quote, rate, spread, source_amount_minor,
      target_amount_minor, expires_at, status}`.
    - `GET /api/v1/fx/quotes/{id}` -> estado vigente/vencido.
  - Auditoria best-effort `fx.quote.created` (sin PII).
- **No incluye:** spread dinamico (`E7-T10`), ejecucion (`E7-T11`), UI (`E7-T12`), QA (`E7-T13`).
  No mueve dinero.

## Contexto embebido (decisiones que aplican)

- **Logica (`docs/12#hu25...`):** el cliente ve la cotizacion; al solicitar, el sistema **congela la
  tasa por 30 s** (`fx_quotes`); si expira, se cancela y se recotiza.
- **Tabla (`docs/03b#10.2`):** `fx_quotes(base, quote, rate, spread, source_amount_minor,
  target_amount_minor, expires_at, status)`; `status` `ACTIVE`/`EXPIRED`/`CONSUMED`/`CANCELLED`.
- **Dinero:** `Decimal` para tasa/spread; `target_amount_minor` entero; nunca `float`.
- **Vigencia:** `expires_at` se calcula con reloj del servidor (UTC); no se confia en el cliente.
- **Idempotencia:** `POST /quotes` con clave opcional; misma clave/cuerpo = misma cotizacion;
  cuerpo distinto = `CONFLICT`.
- **Frontera:** `fx` es dueno de `fx_rates`/`fx_quotes`; no toca `accounts`/`transactions`/`ledger`.
- **Sin PII:** `user_id` UUID; sin datos personales en respuestas/logs.

## Modelo de datos

No crea tablas: usa `fx_rates`/`fx_quotes` (`E7-T01`). `fx.quote_ttl_seconds` se siembra en
`config.parameters` (default `30`).

## API / eventos

- **Endpoints:** `GET /fx/rates`, `POST /fx/quotes`, `GET /fx/quotes/{id}`.
- **Eventos emitidos:** ninguno; auditoria `fx.quote.created`.
- **Eventos consumidos:** ninguno.
- **Errores:** `VALIDATION_ERROR` (par/monto), `NOT_FOUND` (cotizacion ajena), `CONFLICT`
  (idempotencia), `QUOTE_EXPIRED` (si se intenta ejecutar; lo usa `E7-T11`).

## Reglas de negocio

- `base != quote`; monto `> 0`; tasa `> 0`.
- `expires_at` = creacion + TTL (30 s default); el estado efectivo se calcula on-read.
- Una cotizacion `EXPIRED` no se puede ejecutar; el cliente debe recotizar.
- `target_amount_minor` se calcula con la tasa+spread congelados; no se recalcula al leer.
- El titular solo ve sus cotizaciones; ajeno -> `404`.
- Sin PII en logs.

## Criterios de aceptacion (CA)

- `CA-01` (HU25 CA-01): `POST /fx/quotes` congela tasa/spread/montos y `expires_at` a 30 s.
- `CA-02`: `GET /fx/rates` devuelve la tasa vigente con `source`/`ttl`; se persiste el snapshot.
- `CA-03`: una cotizacion vencida se reporta `EXPIRED` y no se puede ejecutar; el cliente puede
  recotizar.
- `CA-04`: montos/tasas exactos (sin `float`); ajeno -> `404`; RBAC del titular.
- `CA-05`: `pytest`/`ruff`/`black` y `alembic check` en verde; sin PII.

## Pruebas requeridas

- Tasas: par soportado/no soportado; snapshot persistido.
- Cotizacion: calculo de `target_amount_minor`, TTL, estado `ACTIVE`.
- Expiracion: on-read a los 30 s -> `EXPIRED`; no ejecutable.
- Idempotencia: misma clave/cuerpo; cuerpo distinto -> `409`.
- Aislamiento: cotizacion de otro usuario -> `404`.
- No mueve dinero.
