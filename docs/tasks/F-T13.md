## Objetivo

Integrar la pantalla de conciliacion de `E5-T21` en el **shell del panel** (`F-T12`): ruta
`/operations`, guard del rol `operations_analyst`, entrada de menu, estados globales y pruebas
E2E de acceso por rol. **No reconstruye** la pantalla de dominio; la consume tal cual.

## Alcance

- **Incluye:**
  - Ruta protegida `/operations` (y subrutas si `E5-T21` las define) con `RoleGuard`
    `operations_analyst`.
  - Entrada de menu "Operaciones / Conciliacion" visible solo para el rol; breadcrumbs/titulo.
  - Wiring de estados globales (cargando/error de sesion/`403`) alrededor de la feature de `E5-T21`.
  - Pruebas E2E/UI: el rol de operaciones entra y ve la pantalla; otro rol -> `403`; sin token ->
    sesion; navegacion desde el menu.
  - Documentar la ruta y el rol en `admin-web/README.md` y `docs/13#2.4`.
- **No incluye:** la pantalla de dominio (ya la construye `E5-T21`), backend, API nueva, edicion de
  asientos, QA de conciliacion (`E5-T22`).

## Plan de PRs

Un solo PR: rutas/guard/menu + pruebas de integracion. No toca la feature de `E5-T21` salvo imports.

## Reglas de negocio

- Solo `operations_analyst` accede a `/operations`.
- El menu no muestra la entrada a otros roles.
- La sesion/errores globales se manejan en el shell, no en la feature.
- Sin PII/tokens en logs.

## Criterios de aceptacion (CA)

- `CA-01`: `/operations` existe, esta protegida por rol y aparece en el menu solo para operaciones.
- `CA-02`: el rol de operaciones ve la pantalla de `E5-T21`; otro rol -> `403`; sin token -> sesion.
- `CA-03`: navegacion desde el menu y breadcrumbs funcionan; estados globales correctos.
- `CA-04`: `npm test`/`tsc`/lint en verde; la feature de `E5-T21` no se modifica.

## Pruebas requeridas

- E2E/UI: login con rol de operaciones -> menu/ruta; rol distinto -> `403`; sin token -> sesion.
- Navegacion: menu -> `/operations` -> detalle (si aplica) -> back.
- Regresion: rutas de crédito existentes siguen funcionando.
